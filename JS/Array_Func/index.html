Syntax and Array Methods

Spread & Rest

When working with multiple values you can group them using the Rest operator, which will create an array. Within this array you can perform X process (in this case capitalize the first letter) to then be displayed.

Array Methods

Please Provide 3 integer Numbers to perform multiple different operations with different array methods

forEach(): Using this method your input will double.

map(): A second array will be constructed X^2 your input values.

filter(): Creates a second array will only even numbers for display.

reduce(): reduces the contents of the array to a single variable (addition) for display.
